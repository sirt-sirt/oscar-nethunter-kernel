# The exact set of kernel modules present in /vendor_dlkm/lib/modules on the
# stock LineageOS 21 build for oscar (RMX3471 / RMX3472), read straight out of
# an untouched dd of the partition with an EROFS parser. 39 entries.
#
# Every one of these is rebuilt from this tree and packed into the vendor_dlkm
# image we flash. Nothing is "left stock" any more.
#
# The reason is CONFIG_SYSVIPC and CONFIG_USER_NS. Both add members to
# task_struct:
#     #ifdef CONFIG_SYSVIPC
#             struct sysv_sem sysvsem;
#             struct sysv_shm sysvshm;
#     #endif
# which shifts the genksyms CRC of every exported symbol whose signature
# reaches task_struct, cred or nsproxy. A stock module hitting one of those is
# refused with "disagrees about version of symbol" even though its vermagic
# string matches byte for byte. Rebuilding all 39 is the only way to keep both
# the Kali chroot and a working phone.
#
# Order here is irrelevant - the boot load order comes from modules.load.
